# Product Guidelines

## Voice and Tone

เป็นมิตร เข้าใจง่าย เหมาะกับ trader ทั่วไป — friendly and approachable, written for traders not engineers. Avoid jargon; when technical terms are unavoidable, pair them with plain-language context.

## Design Principles

1. **Mobile-first** — every UI decision defaults to portrait iOS Safari; landscape and desktop are progressive enhancements
2. **Simplicity** — the most important number should be visible within 3 seconds of opening the app
3. **Comparison** — always make it easy to see how one account/trader ranks relative to others
4. **History** — past performance data must be preserved and browsable; don't discard context
5. **Visual Analytic** — prefer charts and visual cues over raw data tables where possible

## UI Standards

- Optimized for iOS Safari (portrait and landscape)
- Touch targets minimum 44×44pt
- Real-time indicators (equity beacon, heartbeat blink) must be clearly visible
- Number formatting: full currency with 2 decimals for detail views; compact (K/M) for summary chips
- Timezone: always Bangkok (Asia/Bangkok, UTC+7)
