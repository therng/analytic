# Specification: Expandable Economic Calendar Panel

**Track ID:** eco-cal-expand_20260606
**Type:** Feature
**Created:** 2026-06-06
**Status:** Draft

## Summary

เพิ่มความสามารถ expand/collapse ให้ EconomicCalendarPanel โดยเริ่มต้นหุบแสดงแค่ 1 แถวของ upcoming event พร้อม grabber เมื่อดึงขึ้นจะขยายแสดงรายการ upcoming ทั้งหมดและ event ย้อนหลังพร้อม actual values เลื่อนดูได้ไม่เกิน 1 เดือน

## Context

EconomicCalendarPanel ปัจจุบันแสดงเพียง "next time slot" (สูงสุด 3 events) โดยไม่มี interaction ใด ๆ dashboard ต้องการ panel ที่กะทัดรัดโดย default แต่เปิดดู context ครบได้เมื่อต้องการ — สอดคล้องกับแนว mobile-first ของ analytic

## User Story

As a trader, I want to see upcoming and historical USD High Impact events in one panel so that I can plan trades around key economic data releases without leaving the dashboard.

## Acceptance Criteria

- [ ] Collapsed state: แสดง 1 upcoming event (หรือ event ถัดไปที่ใกล้ที่สุด) + drag grabber
- [ ] Expanded state: แสดง upcoming events ทั้งหมดในสัปดาห์ปัจจุบัน/ถัดไป + historical events พร้อม actual values ย้อนหลังไม่เกิน 30 วัน
- [ ] Scroll ผ่าน event list ใน expanded state ได้ (bounded ≤ 30 วัน)
- [ ] API `/api/economic-events` รองรับ `?scope=expanded` เพื่อ fetch ข้อมูลเพิ่มเติม (lastweek + nextweek feeds)
- [ ] Animation ใช้ framer-motion (drag gesture + spring transition)
- [ ] Historical events แสดง actual value ที่ highlight ต่างจาก upcoming

## Dependencies

- framer-motion (เพิ่มเป็น dependency ใหม่)
- Forex Factory CDN feeds: `ff_calendar_thisweek.json`, `ff_calendar_lastweek.json`, `ff_calendar_nextweek.json`
- component ที่มีอยู่: `EconomicCalendarPanel`, `/api/economic-events`

## Out of Scope

- Medium/Low impact events (คง filter เฉพาะ High + Holiday)
- Non-USD currencies
- Push notification / alert เมื่อ event ถึงเวลา
- Charting / visualization ของ historical indicator values
- Data เก่ากว่า 30 วัน

## Technical Notes

- ใช้ framer-motion `motion.div` + `drag="y"` หรือ `AnimatePresence` สำหรับ expand/collapse transition
- Collapsed height: ประมาณ 44px (1 row + header grabber)
- Expanded height: `min(60vh, เนื้อหาจริง)` พร้อม overflow-y scroll
- API เพิ่ม query param `?scope=expanded` → fetch 3 feeds พร้อมกัน (lastweek, thisweek, nextweek), merge, filter USD High, sort chrono
- Section dividers ใน expanded list: "Past", "Today", "Upcoming" โดย dateLabel
- ไม่มี state persistence — collapse กลับทุกครั้งที่ refresh
