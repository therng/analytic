# Specification: iOS Native App — Liquid Glass Design System (iOS 26)

**Track ID:** ios-native-app_20260610
**Type:** Feature
**Created:** 2026-06-10
**Status:** Draft

## Summary

Build a native iOS application for the Analytic trading dashboard using the iOS 26 Liquid Glass design system and Swift, delivering real-time portfolio monitoring and trading analytics with a fully native Apple experience.

## Context

Analytic is an operational trading monitor for MT5-style account data, built for algo fund investors who need real-time visibility across multiple accounts. The existing system is a Next.js web app (mobile-optimized) with a FastAPI backend, PostgreSQL/Prisma data layer, and Redis pub/sub for real-time updates. This track extends the product with a dedicated iOS native client that consumes the existing API layer and brings the experience to the Apple platform with platform-native UX patterns.

## User Story

As a trader/investor, I want to view and analyze market data, portfolio performance, and trading analytics through an iOS native dashboard so that I can make faster trading decisions from real-time data, anywhere.

## Acceptance Criteria

- [ ] Near real-time data updates with minimal latency (WebSocket or polling ≤5s refresh)
- [ ] Seamless experience across Apple ecosystem: iPhone, iPad, and optionally Apple Watch glance view
- [ ] Full, visually rich dashboard: balance/equity curves, KPI chips, P/L heatmap, open positions, economic calendar
- [ ] Utilizes latest Apple technologies: SwiftUI, Swift Concurrency (async/await), Live Activities, WidgetKit (optional)
- [ ] Consistent native experience aligned with iOS 26 Liquid Glass HIG — translucent materials, fluid animations, system fonts

## Dependencies

- **PostgreSQL/Prisma data layer** — all account, position, deal, snapshot data sourced from existing DB via Next.js API
- **Next.js API routes** — `/api/economic-events`, `/api/news`, account/snapshot endpoints consumed by the iOS client over HTTPS
- **FastAPI WebSocket gateway** — real-time equity/balance beacon events
- **Caddy reverse proxy** — `therng.duckdns.org` (HTTPS, port 443) is the production endpoint the iOS app will connect to

## Out of Scope

1. Trade execution and broker integration (placing/modifying orders)
2. Strategy development, backtesting, and automated trading management
3. Android, Web, Windows, and non-Apple platforms
4. Social trading, copy trading, chat, and community features
5. AI-generated trading signals, predictions, or automated investment decisions

## Technical Notes

- **Language:** Swift (latest stable, targeting iOS 26+)
- **UI Framework:** SwiftUI with iOS 26 Liquid Glass materials (`glassEffect`, `GlassEffectContainer`)
- **Architecture:** MVVM with `@Observable` macro (Swift 5.9+) or TCA if complexity warrants
- **Networking:** `URLSession` async/await + `URLSessionWebSocketTask` for real-time feed
- **Charts:** Swift Charts (native, iOS 16+) for balance/equity curves; custom SwiftUI views for heatmap
- **App target:** iOS 26.0 minimum deployment target; Xcode latest
- **API base URL:** configurable via environment/scheme (points to `therng.duckdns.org` in production)
- **No new backend work required** — iOS app is a pure consumer of existing API surface
