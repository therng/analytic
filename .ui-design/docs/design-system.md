space |\n| 1 | 0.25rem (4px) | Extra tight spacing |\n| 2 | 0.5rem (8px) | Tight spacing |\n| 4 | 1rem (16px) | Compact spacing |\n| 6 | 1.5rem (24px) | Default spacing |\n| 8 | 2rem (32px) | consistent corner rounding (Subtle style):\n\n| Token | Value | Description |\n| --- | --- | --- |\n| none | 0 | No rounding |\n| sm | 0.125rem (2px) | Minimal rounding |\n| base | 0.25rem (4px) | Subtle rounding (default for interactive elements) |\n| md | 0.375rem (6px) | Moderate rounding |\n| lg | 0.5rem (8px) | Noticeable rounding |\n| xl | 0.75rem (12px) | Significant rounding |\n| 2xl | 1rem (16px) | Large rounding for cards |\n| full | 9999px | Fully rounded, pill shape |\n\n## Box Shadows\n\nApply box shadow tokens for consistent elevation and depth:\n\n| Token | Value | Description |\n| --- | --- | --- |\n| sm | 0 1px 2px 0 rgb(0 0 0 / 0.05) | Subtle elevation for small elements |\n| base | 0 1px 3px 0 rgb(0 0 0 / 0.1) | Default elevation |\n| md | 0 4px 6px -1px elements |\n\n## Breakpoints\n\nDefine responsive behavior using these breakpoints:\n\n| Token | Value | Usage |\n| --- | --- | --- |\n| sm | 640px | Small screens (e.g., phones in landscape) |\n| md | 768px | Medium screens (e.g., tablets in portrait) |\n| lg | 1024px | Large screens (e.g., tablets in landscape, small laptops) |\n| xl | 1280px | Extra large screens (e.g., desktop monitors) |\n| 2xl | 1536px | Double extra large screens (e.g., large desktop monitors) |\n\n## Animation\n\n### Durations\n\n| Token | Value | Usage |\n| --- | --- | --- |\n| fast | 150ms | Quick transitions, hover effects |\n| normal | 300ms | Standard transitions, element entrance/exit |\n| slow | 500ms | Deliberate transitions, content changes |\n\n### Easing Functions\n\n| Token | Value | Usage |\n| --- | --- | --- |\n| ease | cubic-bezier(0.4, 0, 0.2, 1) | Default easing (accelerate then decelerate) |\n| easeIn | cubic-bezier(0.4, 0, 1, 1) | Accelerate from start (slow then fast) |\n| easeOut | cubic-bezier(0, 0, 0.2, 1) | Decelerate to end (fast then slow) |\n\n## Usage\n\n### CSS Custom Properties\n\n`css\n.button {\n  background: var(--color-primary-500);\n  padding: var(--spacing-2) var(--spacing-4);\n  border-radius: var(--radius-md);\n}\n`\n\n### Tailwind\n\n`html\n<button class=\"bg-primary-500 px-4 py-2 rounded-md\">Click me</button>\n`\n
