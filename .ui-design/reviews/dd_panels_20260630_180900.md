## Summary

Three panels in the DD sub-cycle were reviewed. BotPnLPanel shows an "empty" message while data is still loading. One dead CSS rule remains.

## Major Issues

### Issue 1: PerformanceRadar — legend หายไป

**Severity:** Major
**Location:** `src/components/trading-monitor/PerformanceRadar.tsx:113`
**Category:** Visual / Usability

**Problem:**
`legend: { show: false }` ปิด ApexCharts legend แต่ไม่มี custom legend DOM element ทดแทน CSS classes `.perf-radar__legend`, `.perf-radar__legend-item--actual`, `.perf-radar__legend-item--bench` มีอยู่ใน globals.css (line 526–557) แต่ไม่ถูก render

**Impact:**
ผู้ใช้ไม่รู้ว่า polygon สีน้ำเงินคือ "ผลจริง" และเส้นประคือ "เกณฑ์" — radar chart อ่านไม่ออกโดยไม่มี legend

**Recommendation:**
เพิ่ม legend DOM element ต่อท้าย `<Chart>` ภายใน `.perf-radar`

```tsx
// After
<div className="perf-radar">
  <Chart ... />
  <div className="perf-radar__legend">
    <span className="perf-radar__legend-item perf-radar__legend-item--actual">ผลจริง</span>
    <span className="perf-radar__legend-item perf-radar__legend-item--bench">เกณฑ์</span>
  </div>
</div>
```

### Issue 2: BotPnLPanel — ไม่มี loading skeleton

**Severity:** Major
**Location:** `src/components/trading-monitor/BotPnLPanel.tsx:449-455`
**Category:** Usability

**Problem:**
เมื่อ `positions` prop เป็น `null` (กำลัง fetch), `aggregate(null)` คืนค่า `[]` → component แสดง "No bot activity for this timeframe." ทันที ทั้งที่ข้อมูลยังไม่มา

**Impact:**
ผู้ใช้เห็น empty state ผิดๆ ก่อนข้อมูลโหลดเสร็จ → สับสน คิดว่าไม่มีบอทเทรด

**Recommendation:**
รับ `loading` prop หรือ detect `positions === null` ว่ากำลัง fetch

```tsx
// Before
if (!bots.length) {
  return (
    <div className="bot-pnl-panel bot-pnl-panel--empty">No bot activity...</div>
  );
}

// After
if (positions === null) {
  return (
    <div
      className="skeleton-chart account-card__chart-skeleton"
      aria-hidden="true"
    />
  );
}
if (!bots.length) {
  return (
    <div className="bot-pnl-panel bot-pnl-panel--empty">
      ไม่มีบอทเทรดในช่วงนี้
    </div>
  );
}
```
