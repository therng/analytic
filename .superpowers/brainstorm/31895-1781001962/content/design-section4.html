Design: Section 4 — Tablet Portrait Overview

TabletPortraitOverview component — 2-col card grid + tap-to-expand detail

Component Structure
// src/components/trading-monitor/TabletPortraitOverview.tsx
export function TabletPortraitOverview({ accounts, refreshKey }: Props) {
  const [expandedId, setExpandedId] = useState<string | null>(null);
  if (expandedId) {
    return <TabletAccountDetail accountId={expandedId} onBack={() => setExpandedId(null)} />;
  }
  return <TabletPortraitGrid accounts={accounts} onSelect={setExpandedId} />;
}

2 internal states: grid overview และ account detail — สลับกันใน component เดียว ไม่ใช้ router หรือ modal

Detail View — tap เปิด account
// TabletAccountDetail.tsx — reuses AccountCard in portrait mode
function TabletAccountDetail({ accountId, onBack }) {
  return (
    <div className="tablet-detail-view">
      <BackBar onBack={onBack} /> // ← กลับ
      <AccountCard account={...} forcePortrait /> // portrait layout เสมอ
    </div>
  );
}
  • forcePortrait prop บน AccountCard — ทำให้ render mobile-portrait layout เสมอ ไม่ว่า layoutTier จะเป็นอะไร
  • Back bar: ← กลับ แตะกลับไป grid — ไม่ใช้ router push (ไม่เสีย scroll position)
  • Framer Motion: slide-in จากขวา, slide-out กลับซ้าย (เหมือน iOS navigation)
  • Data fetch เริ่มตอน tap — lazy load เหมือน portrait mobile ปัจจุบัน
Transition Animation (framer-motion)
// Grid → Detail: slide from right
initial: {{ x: "100%", opacity: 0 }}
animate: {{ x: 0, opacity: 1 }}
exit: {{ x: "100%", opacity: 0 }}
transition: {{ duration: 0.22, ease: "easeOut" }}
