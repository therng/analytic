Design: Section 2 — Mobile Landscape Overflow Fix

600–767px — CSS-only fixes, ไม่แตะ JSX โครงสร้าง account-card--landscape

State Derivation (จาก Section 1 review)
// Single-source evaluation — ป้องกัน race condition
function deriveLayoutTier(): LayoutTier {
  const w = window.innerWidth;
  const portrait = window.matchMedia("(orientation: portrait)").matches;
  if (w >= 1024) return "desktop";
  if (w >= 768 && portrait) return "tablet-portrait";
  if (w >= 768 && !portrait) return "tablet-landscape";
  if (w >= 600) return "mobile-landscape";
  return "mobile-portrait";
}

Hook listens to resize + orientationchange events, calls deriveLayoutTier() once, sets single layoutTier state — mutually exclusive by construction

Root Causes ของ Overflow ปัจจุบัน
🔴 BotPnL — fixed height ล้น
/* เดิม */
--dc-botpnl-h: 170px;
height: var(--dc-botpnl-h); /* fixed! */

บนหน้าจอสูง <600px (landscape) เช่น iPhone SE landscape (568px สูง) — botpnl 170px + heatmap 120px = 290px ซึ่งล้น viewport

🔴 Heatmap — fixed height + no overflow
/* เดิม */
--dc-heatmap-h: 120px;
height: var(--dc-heatmap-h); /* fixed! */
overflow: hidden; /* clip silently */

Grid row ไม่มี max-height guard — เมื่อ chart+KPI+botpnl+heatmap รวมกันเกิน viewport height จะถูก clip โดยไม่มี scroll

🔴 Right panel width — clamp ที่ 320px max ทำให้ content แน่น
/* เดิม */
grid-template-columns: 1fr clamp(240px, 34%, 320px);
/* ที่ 767px → right col = 260px เท่านั้น */

CSS Token Changes — 600–767px
/* grid proportions */
grid-template-columns: 1fr clamp(240px, 34%, 320px)
                   → 1fr clamp(180px, 36%, 260px);

/* grid rows — ให้ BotPnL+Heatmap เล็กลง */
grid-template-rows: minmax(0, 1fr) auto auto
                 → minmax(0, 1fr) clamp(80px, 18vh, 140px) clamp(60px, 14vh, 110px);

/* BotPnL — fluid จาก fixed */
--dc-botpnl-h: 170px → clamp(80px, 18vh, 140px);

/* Heatmap — fluid จาก fixed */
--dc-heatmap-h: 120px → clamp(60px, 14vh, 110px);

/* BotPnL+Heatmap ซ้าย-ขวา เมื่อ viewport height < 500px */
@media (max-height: 500px) {
  /* side-by-side เพื่อ save vertical space */

                     → "middle right" "lower right"; /* botpnl+heatmap merged */
}
