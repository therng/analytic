ปัญหาที่คาดว่าพบ
📱 Mobile Landscape
  • Right panel แคบ (240–320px) เกินไปสำหรับ positions list
  • BotPnL / Heatmap สูงขนาดคงที่ — ล้นเมื่อหน้าจอสั้น
  • EconomicCalendar ไม่มีพื้นที่เพียงพอ
📱 Tablet (iPad)
  • พื้นที่ 768–1023px ไม่ได้ถูกใช้งานให้เต็มที่
  • ไม่มี left column (gauges/radar) ทั้งที่มีพื้นที่
  • Right panel ยังเล็กเกินไปเมื่อเทียบ viewport
คำถาม #1: ปัญหาหลักที่ต้องการแก้คืออะไร?

เลือกได้หลายข้อ — เพื่อกำหนด priority ของ design

A

Tablet ควรมี layout ที่ดีกว่านี้

iPad 768–1023px ควรมีพื้นที่มากกว่า mobile — อยากได้ 3-col หรือ sidebar กว้างขึ้น

B

Panel ใน landscape เล็กเกินไป

Right panel ในแนวนอนแคบมาก — Positions/Calendar/History ไม่สามารถแสดงข้อมูลได้ครบ

C

Content ล้น / ถูก clip

BotPnL หรือ Heatmap ล้น, text ถูกตัด, หรือ scroll ไม่ทำงานในบางส่วน

D

อยากได้ layout ใหม่ทั้งหมดสำหรับ tablet

Tablet ควรมี layout เป็นของตัวเองแบบ desktop-lite — ไม่ใช่แค่ขยาย mobile
